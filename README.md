# Mini Project - Kopi Teman Tugas - Landing Page

Landing page untuk kedai kopi dan tempat nugas mahasiswa "Kopi Teman Tugas". Dibuat untuk memenuhi kriteria Mini Project web interaktif.

## 🚀 Fitur Utama
- **Semantik HTML5**: Menggunakan tag semantik (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- **Layout Fleksibel**: Menerapkan Flexbox dengan pendekatan *mobile first*.
- **Aksesibilitas**: Mendukung navigasi keyboard (`:focus-visible`), Atribut ARIA (`aria-expanded`, `aria-pressed`, `aria-invalid`), serta atribut `alt` deskriptif pada gambar.
- **Responsif**: Tampilan menyesuaikan ukuran layar HP hingga desktop (*breakpoint* 768px).
- **Navigasi Mobile Interaktif**: Hamburger menu responsif berbasis JavaScript.
- **Render Data Dinamis**: Menampilkan daftar fasilitas, menu, dan FAQ secara otomatis dari *array of objects* tanpa `innerHTML`.
- **Filter Kategori Menu**: Menyaring tampilan menu (Kopi, Non-Kopi, Makanan) dan menangani kondisi *empty state*.
- **FAQ Accordion**: Jawaban pertanyaan terbuka/tertutup secara interaktif.
- **Validasi Form Reservasi**: Memeriksa kelayakan input pengguna dan menampilkan ringkasan pesan saat data valid.
- **Mode Gelap (Dark Theme)**: Pengalihan skema warna halaman menggunakan *toggle* class CSS.
- **Tombol Back to Top**: Tombol melayang yang muncul saat di-*scroll* untuk kembali ke atas halaman.

## 🛠️ Teknologi
- HTML5
- CSS3
- JavaScript
